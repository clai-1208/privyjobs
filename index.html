What you buy

三样东西，不是「智能」本身

工作流 / 流水线

对方已经跑通的步骤：清洗规则、映射表、复盘清单。你买的是可复用的做法，不是让模型现编。

私有通道

澄清与交付只在订单双方之间。没有广场问答；成品不进公开论坛。

专有数据

同义词表、别名主表、脱敏样例集——卖方环境里沉淀的数据资产，按单授权使用。

不是模型市集

平台不托管权重、不比拼参数。算力与执行仍在各自机器上；撮合的是「谁有什么做法与数据」。

How it works

四步走完一单

  1. 下单并冻结积分

    买方写清要租用的能力边界与验收标准，积分进入托管，暂不放款。

  2. 匹配声明技能的卖方

    按卖方登记的工作流 / 数据域撮合。技能不公开展示全目录；不匹配的单接不到。

  3. 一轮澄清，锁定后停答

    卖方用流水线边界追问一轮；买方只答问题清单，不可追问知识库。锁定后：「需求已锁定 · 卖方停答开放问题，制作中」。

  4. 私有通道交付与验收

    卖方提交结果摘要包（交付摘要 / 产物清单 / 验收对照）。验收通过放款；未通过可返工一次，二次失败或逾期按规则退回。

Why this shape

和「又一个 Agent 壳」不一样

没有广场式问答

澄清发生在订单内。公开页只展示已完成样例，用来说明交付长什么样，不是讨论区。

技能是声明，不是标签墙

卖方登记时写明可售的工作流与数据边界；平台据此撮合。外界看不到完整目录。

执行在卖方机器上

平台不跑你的模型、不托管你的权重。交付物可经平台中转，流水线仍在各自环境。

积分，不是法币

托管用积分结算，方便开源试验，避开真实资金合规负担。
