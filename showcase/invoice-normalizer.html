发票字段归一化流水线

本页提供真实可下载的短映射脚本与备忘，用于说明「租用工作流后交付物长什么样」。订单故事为演示语境。

Brief（买方原文，已脱敏）

我们有三家供应商导出的发票 CSV，列名中英混用、同义字段不统一。需要租用墨线侧已维护的映射流水线与同义词表：输入任意一种表头，输出固定 schema 的 JSON 行；附回归样例。不是让模型现编字段名。

# normalize_invoice_schema.py — excerpt SCHEMA = ("invoice_date", "vendor", "amount_incl_tax", "currency", "invoice_no") SYNONYMS = { "invoice_date": ["开票日期", "Invoice Date", "date"], "amount_incl_tax": ["价税合计", "Amount(税后)", "total_with_tax"], ... } def map_field(raw: str) -> str | None: key = raw.strip().lower() for canonical, aliases in SYNONYMS.items(): if key in {a.lower() for a in aliases}: return canonical return None # unmapped columns → _unmapped
