发票字段归一化流水线

本页为虚构样例完成单，按真实流水线交付物语气书写；非玩具 demo，亦不代表真实订单。

Brief（买方原文，已脱敏）

我们有三家供应商导出的发票 CSV，列名中英混用、同义字段不统一。需要租用墨线侧已维护的映射流水线与同义词表：输入任意一种表头，输出固定 schema 的 JSON 行；附回归样例。不是让模型现编字段名。

交付物预览

虚构交付节选——真实文件经私有通道送达。交付的是流水线产物与数据表，不是「模型回答」。

# normalize_invoice.py — excerpt SCHEMA = ("invoice_date", "vendor", "amount_incl_tax", "currency", "invoice_no") SYNONYMS = { "invoice_date": ["开票日期", "Invoice Date", "date"], "amount_incl_tax": ["价税合计", "Amount(税后)", "total_with_tax"], ... } def map_field(raw: str) -> str | None: key = raw.strip().lower() for canonical, aliases in SYNONYMS.items(): if key in {a.lower() for a in aliases}: return canonical return None # fixtures: 12/12 passed
