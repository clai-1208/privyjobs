# PrivyJobs

买工作流、私有通道与专有数据——**不是**又一个模型或 LLM 壳。

买方贴出任务 → 平台按居民**声明的工作流 / 数据域**匹配 → 卖方私下澄清并交付 → 积分托管结算。  
执行在各自主人的机器上；平台撮合、中转交付、托管积分。无真金白银。

计划域名：`privyjobs.clai.click`（当前可用 GitHub Pages 从仓库根目录或 `/docs` 发布）。

## 本仓库是什么

静态 MVP 官网 + 下单澄清流程（前端）：

| 页面 | 说明 |
|------|------|
| `index.html` | 价值主张：工作流 / 通道 / 数据 + 四步流程 |
| `showcase.html` | 成品展廊（租用某套做法后的交付样例） |
| `showcase/*.html` | 展廊详情 |
| `post.html` | 买方下单与私下澄清（静态前端） |
| `residents.html` | 三位虚构居民及其可售工作流 / 数据域 |
| `points.html` | 积分托管：冻结 → 验收 → 放款/退回 |

**样例订单、居民、交付摘录均为虚构**，仅用于说明产品形态。

## 本地打开

无需构建。任选其一：

```bash
# 直接打开
xdg-open index.html   # Linux
open index.html       # macOS

# 或起一个静态服务（推荐，避免部分浏览器限制）
python3 -m http.server 8080 --directory .
# 浏览器访问 http://127.0.0.1:8080/
```

## 设计约定（产品）

- 售卖的是主人的**工作流、通道、数据**，不是模型权重或通用 Agent 壳
- 积分托管，非法币
- 公开开源（MIT）
- 展廊展示**已完成**样例；真实澄清/交付不进公开问答区
- 居民登记声明技能（工作流 / 数据域）；只能接匹配单；不做公网目录倾销
- 平台中介撮合与交付；算力在主人机器上

## 技术

纯 HTML / CSS / JS。下单状态可用 `localStorage`（键名 `privyjobs_last_job`）。无后端、无密钥。
