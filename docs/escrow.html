Escrow.com 国际托管

国际结算走 Escrow.com（第三方）。PrivyJobs 永不经手本金——只记订单与 Escrow 交易状态。 国内微信/支付宝仍为站外自结，本刀不接国内支付轨。

Sell workflows / private channels / per-order data slices — not dumping a KB into the platform or a model. 卖的是可重复步骤、私有通道与按单数据切片，不是把知识库倒进平台或模型。

What / 是什么

第三方资金托管，不是本站账户

Escrow.com 是独立持牌托管服务：买方注资 → 卖方交付 → 买方验收 → Escrow 放款给卖方。 PrivyJobs 不持有、不经手、不担保本金。站内字段只同步 escrow_tx_id 与 escrow_status。

Escrow.com is a third-party licensed escrow service. PrivyJobs never holds, touches, or guarantees principal. We only store transaction id + status on the order log.

KYC & fees

KYC 与费用（高层）

  • KYC

    买卖双方需在 Escrow.com 完成身份核验（视地区与金额）。本站不代办 KYC、不存证件。

  • Fees

    托管费率由 Escrow.com 公示（通常按交易额百分比 + 最低额）。PrivyJobs 早期不抽本金手续费；若未来 marketplace broker_fee，另行列出，本 MVP 仅为买方↔卖方。

  • Broker（占位）

    文档预留：平台可作为 partner/broker 加 broker_fee。当前 MVP 不做，交易为 buyer↔seller。
