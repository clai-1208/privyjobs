Shared backend · Contract

后端契约（草案）

面向未来 Cloudflare Worker / 可共享后端的 HTTP 契约。 本站默认仍走浏览器 localStorage；客户端通过 API_BASE（空 = 离线）接缝。 仓内已有可 wrangler dev 的源码：worker/（见 worker/README.md）。 生产未部署——下方静态 mock/v1 仍镜像响应形状；Pages 默认 API_BASE=""。

规则：免费撮合 · 站外自结 · 平台不托管资金；点 = 声誉装饰（非法币、非下单货币）；技能不全量公开 dump；澄清有限轮（演示：卖方回应一轮后锁定）；无论坛广场。 交付为结果摘要包（交付摘要 / 产物清单 / 验收对照），非开放闲聊。 客户端：js/api.js 读 meta[name=privyjobs-api] 或 window.PRIVYJOBS_API_BASE；空则行为与本机演示完全一致。

Client seam

API_BASE 接缝

空（默认）：全部订单 / 积分 / 撮合走 localStorage，烟测不变。
已设置：create / list / clarify / deliver / accept / return 尝试 fetch(API_BASE + "/v1/…")；网络或 HTTP 失败时 toast 一次并回退本机。
未来 Base：https://api.privyjobs.example（示例）
本站 mock：mock/backend-contract.json · mock/v1/*.json
