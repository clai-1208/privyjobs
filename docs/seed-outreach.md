# 种子卖方 · 私信话术模板

对齐产品种子方案：卖**做法 + 数据/通道**，不卖模型；积分托管；澄清与交付仅订单双方；全库不上平台；执行在卖方机器。

**用途**：熟人 / 垂直社群**私聊**复制改写。不做付费投放、不大 V、不发公开招标帖、不建论坛。

**合格对方**：已自己跑通 ≥3 次的可售物（工作流 / 私有通道 / 脱敏数据，三选一）；能订单内私密交付；边界与验收写清；愿意积分试单。排除只会调公开模型、无可复用资产者。

---

## 模板 A · 熟人短问

```
嗨，问你一件小事：你手头有没有已经自己跑通好几次的「做法」——比如清洗/映射流水线、私有渠道对接、或脱敏样例集？

我在做一个演示站 PrivyJobs：买方租用的是别人真实在用的工作流/通道/数据，不是又一个模型壳。现阶段用积分托管试单，澄清和交付只在订单双方之间，知识库不全量上传，执行仍在你机器上。

若你愿意挂一条意向，预登记页填几项就行（一句话能力、边界+验收≤3、脱敏样例、交付形态与周转）。非真下单，先看合不合。链接我私发你。
```

---

## 模板 B · 社群私信（即刻 / V2EX / 独立开发者群）

```
你好——刷到你分享过 [具体作品/流水线一句]，想私聊确认下：那套是否已自己跑通 ≥3 次、能按单私密交付？

PrivyJobs 在找 2–3 个种子卖方：售出工作流/私有通道/专有数据（脱敏），不卖模型。积分阶段、不碰真钱；平台只撮合与托管积分，执行在卖方侧。

若有兴趣，可先预登记意向（非真下单）。我把预登记链接和最小资料清单发你。不方便直接说「跳过」即可，打扰了。
```

---

## 模板 C · 对方问「和模型市集有啥区别」

```
差别就一句：我们撮合的是「谁有什么做法与数据」，不是权重或 API 壳。

- 你卖的是已跑通的步骤 / 通道 / 脱敏数据资产
- 澄清与成品只在订单双方，没有广场问答
- 全库不上平台；算力与执行在你机器
- 现阶段积分冻结→验收→放款或退回，非法币
```

---

## 上架最小资料（约谈时对照）

1. 一句话能力  
2. 边界 + 验收条件 ≤3 条  
3. 脱敏样例（可链或粘贴）  
4. 交付形态与周转（多久能交）  
5. 接单窗口  
6. 可选：积分区间  

预登记页：站点 `/prereg.html`（提交写入本机；可复制 JSON；列表标「预登记 · 非真下单」）。
